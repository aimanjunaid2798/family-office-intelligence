# Build Session Summary

## Approximate Build Time

Approximately **28–32 hours** of active development distributed across the assessment window.

---

## Main Development Sessions

### Session 1 – Project Planning & Environment Setup
- Reviewed assessment requirements.
- Planned the overall pipeline architecture.
- Configured the development environment and project structure.

### Session 2 – Family Office Discovery & Dataset Development
- Developed the discovery workflow.
- Collected candidate Family Office records.
- Cleaned and standardised the dataset.
- Removed duplicate and low-confidence records.

### Session 3 – Data Validation
- Reviewed candidate records.
- Refined inclusion criteria.
- Validated information using multiple public sources where possible.
- Produced the final validated dataset.

### Session 4 – Micro-RAG Development
- Implemented the embedding pipeline.
- Generated vector embeddings.
- Built the FAISS index.
- Connected semantic retrieval with the language model.

### Session 5 – Frontend & Deployment
- Built the Streamlit interface.
- Integrated retrieval with the deployed application.
- Configured deployment and application secrets.
- Performed end-to-end testing.

### Session 6 – Testing & Documentation
- Tested retrieval behaviour using multiple natural language queries.
- Reviewed generated responses.
- Prepared documentation and repository for submission.

---

# AI Assistance

AI tools were used primarily to accelerate implementation, generate initial boilerplate, assist with debugging, and improve documentation drafts.

Final architectural decisions, validation criteria, retrieval workflow, engineering trade-offs, testing, deployment, and refinement of the implementation were reviewed and adjusted manually throughout development.
